# 食養紀錄｜食品清單視覺與分類修正（2026-10-21）

## 已確認的根因
原本 food-list 使用 max-height:360px、display:flex、flex-direction:column，食品卡片預設 flex-shrink:1；在資料量與介面放大時卡片會被壓縮，高度小於內容，名稱、營養標籤和選取按鈕重疊。

## 本次規格與變更
1. 將食品清單改為頁面自然捲動，max-height:none，食品卡片 flex-shrink:0。
2. 卡片採 minmax(0,1fr)+auto 兩欄：左側食品資訊、右側選取；文字可換行，P/F/C 小標籤自動換行，不允許覆蓋按鈕。
3. 主要分類改為單一大尺寸原生 select，減少原本 12 個主選單按鈕的佔位。
4. 超商可從主分類直接選「7-ELEVEN 鮮食」、「全家鮮食」、「萊爾富鮮食」、「OK 超商鮮食」，或先選「超商鮮食」後再選品牌。
5. 選品牌後，以兩欄、至少 48px 高的選項提供「御飯糰、飯糰、微波餐盒、三明治、漢堡、熱壓吐司、沙拉／健康餐、熱食小吃、麵包／甜點、飲品、其他鮮食」，顯示該品牌已收錄筆數。現無品項的常用類型顯示 0 且停用，避免假裝已有商品。
6. 食品目錄既有 sub_category 多為「7-11鮮食」「全家鮮食」，不包含商品類型。food-taxonomy.js 依商品名稱作**介面分類**，不更改 Supabase 的 kcal、蛋白質、脂肪、碳水、審核狀態或來源；無法判定的歸「其他鮮食」。
7. 首次呈現 20 筆，保留「載入更多」、輸入搜尋、份量選擇、餐點記錄等流程。
8. 設定中的 90/100/110/120% UI 大小保留；新增單元與真 Chromium 版面回歸測試。

## 驗收案例
- 全部食物：連續 14 張長名稱卡片，分別在 90/100/110/120% 版面測試，卡片不重疊、不縮成固定高度、不出現橫向溢位。
- 7-ELEVEN：新極上飯糰歸御飯糰、熟成御飯糰歸御飯糰、一般飯糰歸飯糰、便當歸微波餐盒、三明治歸三明治、熱壓吐司歸熱壓吐司。
- 全家等品牌共享相同分類，而不會混進其他品牌食品。
- 點選分類後選取食品、修改份量、返回及新增到今日的舊流程維持。
- 掃碼、登入、通知與外觀設定相關程式沒有動到。
- 資料庫未修改，因此既有食品總數、營養數據和個人飲食紀錄不受此版部署影響。
