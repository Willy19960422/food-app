# 食養紀錄｜食品分類盤點與超商微波食品資料擴充
檢查日期：2026-10-21

## 發現的資料分類錯誤
1. `food_catalog_candidates.category='蛋白健康'` 共 20 筆，實際品牌均為超商：7-ELEVEN 13、全家 7。將來源的主分類統一成「超商鮮食」，透過 `dietary_tags=['蛋白健康']` 保留健康特色。品牌、來源、品名、營養數字、審核狀態不因歸類而改動。
2. 舊食品 `custom_foods` 的分類名稱曾包含「飲品」（40+）、「點心零食」（1）、「營養補充」（6）、「即食食品」（4）、「冷凍食品」（1）、「蛋豆肉」（1），沒有對應到選單主分類。新版使用 `FoodTaxonomy.canonicalCategory`，全部能找到，且不批次更動正式食品的欄位及歷史記錄。
3. 舊版收藏食物流程將 `cat` 覆蓋成「我的常用」，造成原分類下食品消失。現在收藏只保留 `isFav` 狀態，若同名主資料存在則以主資料分類為主。
4. 舊分類直接依蛋白質門檻判定「蛋白健康」，混淆「來源」（超商）與「飲食特色」（蛋白健康）；新版健康系列是橫向篩選條件，與「微波餐盒／飯糰／沙拉／飲品」可以交叉篩選。
5. 新商品分組依商品形式分類，且支援人工核對過的 `product_type` 覆蓋名稱判斷，避免「雞胸餐盒」被誤分成單獨雞胸或「香鮭蛋炒飯」被歸為其他鮮食。

## 品質／風險說明
- 官方網站「商品品名」不等於完整營養標示，也不等於門市持續販售。
- 新增資料的 `source_quality='official_menu'`、`nutrition_status='awaiting_full_label'`、`market_status='unreviewed'`。
- 有官方 kcal 但缺蛋白質／脂肪／碳水者，只能顯示「待補」；不能當成可直接記錄完整四大營養的食品。
- `food_catalog_candidates` 與 `custom_foods` 是不同資料表；一筆正式食品與來源候選品名相似時，前端依既有去重規則避免重複顯示。
- `custom_foods` 358 筆及既有每日紀錄不更動。
- 後續應優先採集實際包裝營養標示，人工核對每份、重量、熱量、P/F/C，才可設定 `official_nutrition` 與 `complete`。
